# DAS-PSC

**DAS-PSC (ПСК)** — отдельная система проектно-строительного контроля: объект → документы → комплектность → этапы → контроль.

## Уже в MVP v0.1

- веб-дашборд и единая карточка объекта;
- безопасный анализ ZIP без распаковки на диск;
- базовая классификация документов по имени и пути;
- извлечение проектного кода и ревизии из имени;
- SHA-256 и поиск точных дубликатов;
- контроль комплектности по шаблону строительного объекта;
- очередь «на ручную проверку»;
- Docker и CI.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -e '.[dev]'
uvicorn app.main:app --reload --port 8080
```

Открыть `http://127.0.0.1:8080`.

Или:

```bash
docker compose up --build
```

## Проверка

```bash
pytest -q
```

## Данные

Реальные проектные архивы, исполнительная документация, сертификаты, фотографии, персональные данные и NAS-реквизиты **не коммитятся в Git**. Для рабочих данных используем `/data`, NAS или другое внешнее хранилище.

> Репозиторий необходимо перевести в **Private** до подключения реальных объектов.

Подробный план: [`docs/MVP_SCOPE.md`](docs/MVP_SCOPE.md).

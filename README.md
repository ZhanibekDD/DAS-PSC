# DAS-PSC

ПСК — проектно-строительный контроль.

Разработка рабочего пилота v0.2 находится в PR #1, ветка `feat/psc-mvp-v0.1`.

Реальные проектные документы, БД, NAS-пути и учетные данные не коммитятся в Git. Новая версия добавляет постоянный реестр, подтверждение импортов, ручную проверку категорий и чтение NAS без изменения исходников.

Полная инструкция запуска и проверки включена в следующий атомарный commit пилота.

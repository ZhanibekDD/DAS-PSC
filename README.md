# DAS-PSC

**ПСК — проектно-строительный контроль** для ведения строительных объектов, документов, комплектности и хода работ.

## MVP v0.1

Первая версия должна дать рабочую модель на одном объекте:

- список объектов;
- единая карточка объекта;
- импорт ZIP/NAS без автоматического перемещения исходников;
- реестр файлов и базовая классификация;
- контроль комплектности по шаблону папки объекта;
- ход строительства и статусы этапов;
- очередь ручной проверки для неоднозначных файлов.

## Безопасность данных

Реальные проектные архивы, исполнительная документация, сертификаты, фото, персональные данные и NAS-учётные данные **не коммитятся в Git**. Они подключаются только локально/на сервере через внешнее хранилище.

> Перед использованием реальных данных репозиторий должен быть переведён в **Private**.
